Created a UGV which uses computer vision on Jetson with stereo camera to navigate alongside ultrasonic and lidar sensors to create a mapping of its surroundings.

UVM testbench for FPU

Created a UVM testbench for FPU which takes into account for addition, sub, multiplication and division alongside other edge cases.

Computer vision navigation based UAV (Unmanned aerial vehichle)

Created a UAV which uses waypoint navigation for autonomous flight and computer vision based flight for tracking objects.

Embedded Systems Project

Created the game "Who Wabts to be a Millionaire" using STM32, multi-device UART communication and SPI for display.

PCB Project @ J&J

Multicore Processors with multithreading
