Computer Vision Navigation based UAV (MAVERIC)

Created a UAV which uses waypoint navigation for autonomous flight and computer vision based flight for tracking objects.

Purpose of the Project

The purpose of this UAV project was to explore autonomous aerial robotics, focusing on navigation, real-time object detection, and autonomous waypoint-based flight. It serves as a testbed for integrating computer vision into guidance and control loops for UAV systems.

Specifications & Achievements

  • Autonomous waypoint navigation with onboard GPS and IMU sensors.
  • Computer vision module for object tracking and path correction.
  • Stable hover and flight performance under varying wind conditions.
  • Onboard embedded system for sensor fusion and flight control.
  • Designed and tested flight algorithms ensuring reliable operation in test flights.

Who Wants to be a Millionaire

Role: Team Captain for SPARK Challenge (project competition at Purdue)

Led a team of four to create this STM32-based project for the Purdue SPARK Challenge. Video here is one of the initial test runs of the project. Project is a real time question changing interactive game based off of Who Wants to be a Millionaire. It involves usage of SD card to load the questions which are then assigned a specific value of $100, $1000 and so on as in the real game. User can input their custom username and has 10 seconds to answer each question and if they win their name is displayed on a leaderboard.

Embedded system concepts applied in this project

  • PWM for the timer to work
  • Interrupts for the Keypad
  • SPI for the display on the TFTs
  • UART for the communication between the two STM32s to allow live update of score
  • Timers for the Question time

PART (Purdue Aerial Robotics Team)

Role: GNC (guidance navigation controls) team member

An autnomous UAV (quadcopter) which had approximately 600g load capacity and would drop projectiles at its given waypoint location. I, being in the GNC team, was responsible for helping create the alogirthm which would allow us to decide which waypoint the quadcopter would take. We created a weighted matrix which took into account several factors such as wind speed, latitude and longitude, current angular velocity and then using Djikstras Algorithm determined which path the UAV should take.

Arduino Projects (more on youtube playlist)

Feedback Control Systems prototype

Using Arduino designed a feedback control system for a motor system which would allow the user to turn it on using a magnet due to using hall effect sensors, alongside having an automatic shutdown capability through use of a thermistor. Ultrasonic sensors were used to detect objects and PWM was used to control motor speed in proportion to the detection by ultrasonic sensor to slow down the motor if an object approaches it. This system was part of my instruction manual that I made at J&J to help people from non electrical engineering backgrounds learn arduino and basic electronics.
